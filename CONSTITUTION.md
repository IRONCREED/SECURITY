# Конституция проекта IRONCREED Security

Идентификатор: `ics-constitution-adoption-001`.

Редакция: `0.1.0`.

Дата принятия: 2026-08-28.

Настоящий акт принимает без изменения универсальный нормативный корпус
«Конституции кода» по точной ссылке:

- официальный источник:
  `https://github.com/FOP-Oksana-Dubinetska/code-constitution`;
- Git-коммит: `220dc9c286ae06f8b6ed60cdda75112eed0408ed`;
- путь сабмодуля: `/code-constitution`;
- канонический файл: `locales/ru/CONSTITUTION_CODE.md`;
- SHA-256 канонического файла:
  `864bf72a9072d394d77d09de40089f8f0f3ecc0ff8f77c41ef173f0852adf2ee`;
- пространство устойчивых идентификаторов: `kc-*`;
- число положений в принятом корпусе: `334`.

Текст корпуса включается в проект по закреплённой редакции сабмодуля. Локальная
копия корпуса не создаётся. Проектная конкретизация содержится в
[`governance/PROFILE.md`](governance/PROFILE.md), а производные нормы — в
[`governance/legislation/`](governance/legislation/). Локальные положения
используют пространство `ics-*` и не переопределяют идентификаторы `kc-*`.

Приоритет источников определяется следующим порядком:

1. обязательное право и правила платформ распространения;
2. правила официального каталога WordPress.org и официальные WordPress Coding
   Standards в их предметной области;
3. принятый универсальный корпус «Конституции кода»;
4. ратифицированный Учредительный профиль;
5. действующее проектное Законодательство;
6. удостоверенное решение в пределах предоставленного полномочия;
7. реализация и фактическая практика.

Ни сложившийся код, ни удобство выпуска, ни автоматическая зелёная проверка не
создают исключение из внешних правил WordPress.org. Расхождение устраняется в
исходном коде, пакете выпуска и нормативных документах одной проверяемой
редакцией.

Русский текст принятой универсальной редакции является нормативным основанием
первого проектного цикла. Английский язык является исходным языком
пользовательских строк, публичной документации плагинов и коммуникации с
WordPress.org. Переводы интерфейса создаются стандартными средствами WordPress.

Изменение закреплённого источника, хеша, пространства идентификаторов либо
порядка приоритета проходит как конституционная поправка. Исходный нормативный
текст сохраняет собственную лицензию и атрибуцию.
