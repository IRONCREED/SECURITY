# Licensing overrides

These declarations apply only to original material owned by the repository
rights holder. They preserve all mandatory third-party terms.

| Scope or path | Applied license or restriction | Reason |
| --- | --- | --- |
| `plugins/**` | `GPL-2.0-or-later` | Every plugin subtree remains GPL-compatible as one independently distributed work. |
| `code-constitution/**` | Upstream license and attribution | The pinned submodule retains its source terms. |
| `.licensing-policy/**` | `LicenseRef-FOPOD-Repository-Policy-1.0` and upstream notices | The policy source retains its restricted policy license. |
| IRONCREED names, marks, logos, and visual identity | No license granted; all rights reserved | Publishing plugin code does not grant brand rights. |
