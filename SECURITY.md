# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities privately to `sam@zhovten.games`. Include the
affected plugin and version, the smallest reproducible description, security
impact, and any proposed mitigation. Do not include production credentials,
unredacted logs, or personal data unnecessary to reproduce the issue.

Do not open a public issue before maintainers have had a reasonable opportunity
to assess and coordinate a fix. Confirmed vulnerabilities will be handled
through a private fix, coordinated disclosure, a versioned release, and
WordPress.org procedures when a directory release is affected.

## Supported versions

No production version is currently released. A supported-version table will be
added before the first stable release.
