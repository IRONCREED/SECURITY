# Plugins

Each child directory is the canonical development source for one independently
installable WordPress plugin. A plugin owns its slug, Product ID, package,
version, readme, license notice, storage, migration, tests, and release history.

| Directory | Product ID | Theme | Status |
| --- | --- | --- | --- |
| `ironcreed-request-log/` | `ironcreed/request-log` | `security` | Approved implementation brief; no code yet |

A new directory requires a product decision, immutable Product ID, Suite theme,
human-readable implementation brief, licensing declaration, and release plan.
