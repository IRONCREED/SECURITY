# IRONCREED Request Log

Status: specification; implementation has not started.

The approved version-1.0 contract is `IMPLEMENTATION-BRIEF.md`. The first
release will provide a bounded, privacy-aware view of concrete requests that
reach the WordPress runtime. It will not claim visibility into CDN, WAF,
web-server, cache, or static-file traffic.

This directory is licensed under `GPL-2.0-or-later` by the root override. A
release-ready implementation must include its own GPL notice and
WordPress.org-compatible `readme.txt`.
