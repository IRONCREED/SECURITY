# Licensing

This repository applies the shared repository licensing policy published at:

- Policy source:
  `https://github.com/FOP-Oksana-Dubinetska/repository-licensing-policy`
- Git submodule path: `.licensing-policy/`
- Pinned policy version: `6e4c2627717c079827ed4aa9044a5346b3ea3ddb`

The policy submodule is incorporated by reference. Its presence does not
automatically license this repository: this file declares the licenses that
apply to this repository.

## Default licensing map

Unless a more specific third-party notice, subtree notice, file-level notice,
or project-specific override applies:

| Scope | Default license |
| --- | --- |
| Original prose, documentation, publication sources, and non-brand editorial materials | `CC-BY-SA-4.0` |
| Original source code, scripts, tests, examples, reusable schemas, and templates | `MIT` |
| Names, logos, trademarks, brand assets, and visual identity | No license granted; all rights reserved |
| Third-party materials | Their original upstream licenses and notices |

## Project-specific overrides

[`LICENSING-OVERRIDES.md`](LICENSING-OVERRIDES.md) assigns
`GPL-2.0-or-later` to distributable WordPress-plugin subtrees. This override
supports compatibility with WordPress and the official Plugin Directory.

## Precedence

1. mandatory third-party upstream terms and notices;
2. file-level notices and SPDX identifiers;
3. subtree-specific `LICENSE`, `LICENSE.md`, or `NOTICE` files;
4. `LICENSING-OVERRIDES.md`;
5. the default licensing map above.

An override may replace a default only for material owned by the repository
rights holder. It cannot weaken third-party obligations.

## Reference texts

Reference texts supplied by the pinned policy are available at:

- `.licensing-policy/LICENSES/CC-BY-SA-4.0.txt`;
- `.licensing-policy/LICENSES/MIT.txt`.

Each release-ready WordPress plugin must include the complete text or canonical
notice required for `GPL-2.0-or-later` inside its distributable directory.

## Branding

No permission to reuse names, logos, trademarks, brand assets, or visual
identity elements is granted unless explicitly stated in writing.
